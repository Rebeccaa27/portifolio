# Portfólio — Rebeca Alves

Página estática em português com três projetos de automação, layout responsivo e prints ampliáveis. HTML, CSS e JavaScript, sem etapa de build.

## Publicação no GitHub Pages

Envie estes arquivos e a pasta `assets` para a raiz de um repositório público. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e salve.

## Atualização

- Textos e projetos: `index.html`.
- Cores, fontes e layout: `style.css`.
- Visualizador de prints: `script.js`.
- Imagens: `assets/`.

Os prints foram fornecidos pela autora. Os textos descrevem as funcionalidades relatadas, sem métricas de impacto não verificadas. Projetos de IA generativa poderão ser acrescentados quando o material estiver pronto.
