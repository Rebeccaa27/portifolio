01 / AGENDAMENTOSIntegração entre sistemas

Da reserva ao lembrete.
Uma jornada conectada.

Integração do Cal.com com a plataforma de atendimento para comunicar agendamentos, alterações e lembretes via API.

A necessidade

Manter a comunicação com o cliente alinhada às reservas e às mudanças na agenda, além de lembrar os compromissos próximos.

O que desenvolvi

Um fluxo que recebe eventos via webhook e envia confirmações, cancelamentos e reagendamentos. Uma rotina consulta o banco de dados a cada cinco minutos para identificar os lembretes a enviar.

Como funciona

Mensagens enviadas pela API da plataforma de atendimento, com lembretes no dia do compromisso, uma hora antes e dez minutos antes.

02 / ATENDIMENTOLógica em JavaScript

O primeiro contato,
com o caminho certo.

Triagem inicial que identifica novos contatos e conduz a coleta de informações antes do atendimento.

A necessidade

Iniciar a triagem para novos contatos, sem reiniciar esse processo para quem já estava na base.

O que desenvolvi

Uma verificação em JavaScript, com consulta ao contato e ao histórico, para decidir se a triagem deve seguir e qual etapa executar.

Como funciona

O fluxo envia a apresentação, coleta nome e cidade e atualiza as etiquetas para encaminhar o contato ao atendimento.

n8n · JavaScript · Webhooks · API do Atende Direito
03 / OPERAÇÃORegras de negócio

Pipeline organizado.
Uma etapa a menos à mão.

Exclusão automática de cards a partir da movimentação para uma etapa específica no Atende Direito.

A necessidade

Executar a remoção do card quando o contato chega à etapa definida pela operação.

O que desenvolvi

Um fluxo acionado por webhook que busca o negócio pelo identificador ou consulta os cards associados ao contato.

Como funciona

Quando encontra o card, realiza a exclusão via API. Se nenhum card é encontrado, encerra o fluxo sem executar a exclusão.

n8n · Webhooks · APIs · Condicionais
